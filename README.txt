HACK-FIN.RU — РУБРИКА «ИССЛЕДОВАНИЯ»
Обновлено: 30.08.2026

ФАЙЛЫ ДЛЯ ЗАГРУЗКИ В КОРЕНЬ САЙТА
1. index.html — обновлённая главная: показывает два последних исследования.
2. research.html — общий каталог и фильтры по рубрикам.
3. research-data.js — ЕДИНСТВЕННЫЙ список карточек исследований.
4. research-list.js — автоматически выводит карточки на главной, в каталоге и внутри статей.
5. research-components.css — общий дизайн карточек.
6. peredel-sobstvennosti-rossiya-2022-2026.html — первое исследование.
7. marketplaces-ozon-wildberries-usa-russia.html — исследование о маркетплейсах.
8. _article-template.html — заготовка для следующей статьи.
9. sitemap.xml и robots.txt — служебные файлы для поисковых систем.
10. assets/ — локальные изображения для красивых превью статей в соцсетях.

КАК ДОБАВИТЬ СЛЕДУЮЩЕЕ ИССЛЕДОВАНИЕ
1. Сделать новый HTML-файл статьи, взяв за основу готовую статью или _article-template.html.
2. В research-data.js добавить ОДИН объект с названием, ссылкой, датой и описанием. Позиция объекта в файле не важна: сортировка идёт по published.
3. Добавить URL статьи в sitemap.xml.

После пункта 2 карточка автоматически появится:
— в каталоге research.html;
— среди двух последних материалов на главной;
— в блоках «Читайте также» внутри старых статей.

ВАЖНО
— Новые материалы сортируются по полю published автоматически.
— В поле published используйте формат YYYY-MM-DD.
— Все файлы должны лежать рядом в корне сайта.
— alexandra-photo.JPG остаётся на прежнем месте.
— Не загружайте файлы .bak-v1/.bak-v2/.bak-v3: это локальные резервные копии.
